# Replaying a disputed score

Two public releases answer different questions. For MMLU high-school statistics, compare test stems against the original development/validation files (split hygiene) and the independently annotated MMLU-Redux release (known republication control). Join reviewer evidence on stem and ordered choices, not row number. A contradiction is a review case, not permission to rewrite the key. Adjudicate the same frozen choices repeatedly: the deterministic control selects by lexical similarity; an optional localhost-only model selects an answer blind to both keys. Record every vote and compare within-item repeat disagreement, not variance across easy/hard questions.

For Openbenchmarks Lookalikes P@10, keep each seed's integer numerator, denominator 10 and missingness. Compare the same seeds within each pair; never simulate per-seed results from aggregate percentages. Predeclare two contrasts: CompanyEnrich vs PredictLeads (top two) and CompanyEnrich vs Exa (widely used search baseline). Resample paired seed differences; use Bonferroni intervals across the two contrasts. Conditional on these seeds, the observed board is exact: uncertainty is about other similar seeds, not measurement noise in published arithmetic. These exploratory comparisons do not certify the entire ranking.

The Open LLM Leaderboard archive also publishes both per-question predictions and matching score summaries for the April 19, 2024 five-shot Llama 3 8B base/Instruct runs. Use these actual frozen selections rather than generating surrogate answers. Match full stems and ordered choices, verify the published accuracy for every item and run, inspect same-alternative disagreement against Redux, and report the single paired subject-level gap independently of the Lookalikes contrast family. Regrade both frozen selections from the same blind local judge votes. Judge-replay receipts bind raw votes to the input digest; means and intervals must be reproducible without rerunning inference.

## Implementation and verification plan

1. Freeze licensed, source-hashed public inputs and normalized row IDs; no employer artifacts, credentials or vendor reruns. Data refresh aborts on provenance/coverage mismatch rather than combining releases. Ship normalized fixtures; no model or network dependency in ordinary runs.
2. Implement exact token-shingle containment and cosine retrieval using corpus-fit TF-IDF + truncated SVD document embeddings (LSA). Fit only on the reference corpus. Keep both nearest IDs, scores and thresholds. Prefer this inspectable baseline to requiring large transformer weights. It can miss paraphrases and matches templates; do not infer model exposure.
3. Exercise known copies, unseen vocabulary, disagreement vs missing evidence, deterministic vs changing votes, invalid/failed model calls, paired vs unmatched seeds and reproduction against source aggregates. Unit tests for algorithms, integration tests for the CLI and HTTP protocol, live local model smoke when available. No test of proprietary training membership or judge truth: neither is observed.
4. Emit machine-readable evidence and a short human reading guide. Rollout is a local command against version-controlled immutable files; changing a source, rubric or threshold requires regenerating a separately identified report.
